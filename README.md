# Cataclysm Mod

The open source GitHub repository for people to test in progress stuff and propose fixes and changes.

Cataclysm is content addon for the Calamity Mod using some content and sprites inspired from pages on the Calamity Fandom Wiki. Unlike Calamity: Community Remix however, the majority content in this mod uses original concepts and puts its own spin on the Fandom content, aiming to be more quality addon rather than being a joke mod (but we still have some humor :D).

This mod also has 3 new semi-original bosse to further expand one’s play though.
